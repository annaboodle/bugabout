      How Bugabout works

      Every little traveler leaves a very long trail.

      1. Sign in at geocaching.com. The trackable page is public, but its map download is empty unless you are signed in.
      2. Open the trackable page for the bug you want to follow — the one whose web address contains its public TB code.
      3. Choose “View in Google Earth” on that page. It saves a .kml file to your downloads.
      4. Bring it here with Open KML, or drag the file anywhere onto this page.
      5. Press play and watch the journey unfold cache by cache.

      The file is read in your browser and never uploaded. KML holds ordered cache coordinates and total mileage only — no visit dates, log text, cache names, or photos — so Bugabout labels what is missing instead of inventing it. Countries are worked out from each stop’s coordinates. Never share the private tracking code printed on the bug itself; the public TB code is all Bugabout needs.
